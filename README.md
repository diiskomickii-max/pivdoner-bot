# ПивДонер — Telegram-бот предзаказа

Telegram-бот для кафе: гость собирает корзину и делает предзаказ на самовывоз,
заказ падает в группу заведения с кнопками статуса и оплаты.

## Возможности

- 📋 Меню по категориям с количеством и корзиной
- 🕐 Предзаказ на время («как можно скорее», +20/40/60 мин, своё время)
- 💳 Выбор оплаты: онлайн по ссылке банка / на месте
- 🔔 Уведомления в группу заведения + push клиенту при смене статуса
- 📊 Отчёт по продажам за день, активные заказы
- 👤 Личный кабинет: история заказов, бонусы
- 🎮 Мини-игра «кубик» с ежедневными бонусами
- 🧹 Автоочистка чата — сообщения бота удаляются после шага

## Запуск локально

```bash
pip install -r requirements.txt
# создай .env по образцу .env.example
python bot.py
```

## Переменные окружения (.env)

```
BOT_TOKEN=токен от @BotFather
MANAGER_CHAT_ID=id группы заведения (с минусом)
PAYMENT_URL=https://pay.example.com/pay?order={order_id}&sum={amount}
PAYMENT_ENABLED=1
```

## Структура

| Файл | Назначение |
|---|---|
| `bot.py` | точка входа |
| `handlers.py` | логика заказа, статусы, админ-панель |
| `keyboards.py` | все кнопки |
| `menu.py` | меню кафе — источник данных (потом из r_keeper) |
| `db.py` | SQLite: заказы, гости, бонусы |
| `states.py` | FSM оформления |
| `config.py` | конфиг из .env |
