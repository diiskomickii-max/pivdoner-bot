# ПивДонер — Telegram-бот предзаказа (Боевая версия)

Telegram-бот предзаказа и самовывоза для кафе стритфуда **«ПивДонер»** (г. Минск).  
Гость собирает корзину блюд и оформляет предзаказ на удобное время, а уведомление с кнопками управления заказом падает напрямую в рабочую группу заведения (`MANAGER_CHAT_ID`).

---

## 🌟 Возможности бота

- 📋 **Меню по категориям** (шаурма, донеры, закуски, напитки) с выбором количества и корзиной
- 🕐 **Предзаказ на время**: «как можно скорее», +20/40/60 минут или точное своё время
- 💳 **Выбор способа оплаты**: онлайн по банковской ссылке / ЕРИП или при получении
- 🔔 **Уведомления персоналу**: заказы падают в Telegram-группу заведения с кнопками статуса
- 🔄 **Push-уведомления гостю**: автоматическое оповещение при смене статуса заказа («Принят», «Готовится», «Готов»)
- 📊 **Админ-панель**: отчёт по продажам за смену/день, просмотр активных заказов
- 👤 **Личный кабинет гостя**: история заказов, баланс бонусных рублей
- 🎮 **Мини-игра «Кубик»**: ежедневный интерактивный розыгрыш бонусных баллов
- 🧹 **Автоочистка чата**: бот автоматически удаляет промежуточные сообщения диалога

## 🚀 Быстрый запуск локально

```bash
# 1. Клонируй репозиторий
git clone https://github.com/diiskomickii-max/pivdoner-bot.git
cd pivdoner-bot

# 2. Установи зависимости
pip install -r requirements.txt

# 3. Создай .env по образцу
cp .env.example .env

# 4. Запусти бота
python bot.py
```

## ⚙️ Переменные окружения (`.env`)

```env
BOT_TOKEN=токен_от_@BotFather
MANAGER_CHAT_ID=-100xxxxxxxxxx  # ID группы заведения (с минусом)
PAYMENT_URL=https://pay.example.com/pay?order={order_id}&sum={amount}
PAYMENT_ENABLED=1
```

## ☁️ Деплой 24/7

В репозитории подготовлены готовые конфигурации для развёртывания:
- **Render**: файлы `render.yaml` и `Procfile` (тип Background Worker)
- **Railway / Docker**: файл `Dockerfile`
- **VPS (Ubuntu)**: Supervisor или systemd service
- Подробное руководство по развёртыванию см. в [`DEPLOY.md`](DEPLOY.md).

## 📖 Инструкция для администраторов

Полная инструкция для персонала заведения по обработке заказов на кассе доступна в файле [`ADMIN_GUIDE.md`](ADMIN_GUIDE.md).

## 📁 Структура проекта

| Файл | Назначение |
|---|---|
| `bot.py` | Точка входа, запуск поллинга aiogram 3 |
| `handlers.py` | Логика предзаказа, корзины, смены статусов, админки |
| `keyboards.py` | Инлайн и реплай-клавиатуры |
| `menu.py` | Каталог блюд кафе (цены, граммовки, состав) |
| `db.py` | SQLite база данных: заказы, клиенты, бонусы |
| `states.py` | Машина состояний FSM оформления |
| `config.py` | Загрузка конфигурации из `.env` |
| `render.yaml` | Спецификация автодеплоя на Render |
| `Dockerfile` | Контейнеризация для Railway / Docker |
| `Procfile` | Команда запуска воркера |
| `ADMIN_GUIDE.md` | Памятка для кассира и администратора |
| `DEPLOY.md` | Инструкция по деплою на облачные сервисы |
